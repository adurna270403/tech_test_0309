An unlevered, cost-aware, daily-rebalanced book of four uncorrelated sleeves:
a trend-gated **US equity core**, a **BTC EMA+RSI trend** sleeve, a
**trend-gated defensive** sleeve (gold / duration / dollar), and a crypto
**same-weekday cross-sectional momentum** sleeve (Long 2020). Idle cash earns
the causal 13-week T-bill rate.

Headline: >75% positive months met (75.3% full / 75.0% IS / 75.6% OOS,
93 months from 2019); the 2-4% average-month target is not met
(1.64%/month full, 1.62% OOS, Sharpe 1.43, CAGR 14.0%, MaxDD −15.0%). The
sample starts 2019 — the first date the Binance USDT cross-section has enough
liquid names for the cross-sectional sleeves; the thin 2017-2018 market is
reported separately as a robustness check. The report explains the return miss
via the no-leverage constraint — the book leans on the 100% gross cap nearly all
the time, and sweeping the cap diagnostically shows both targets clear together
only at ~125% gross. `output/REPORT.md` / `output/REPORT.pdf`
(regenerate with `make all`).

## Run everything

```bash
pip install -r requirements.txt
make all        # or: the four commands below
```

Without make:

```bash
python -m pytest tests/ -q     # no-lookahead & engine-correctness tests
python run_backtest.py         # reads frozen snapshot, runs backtest, writes output/
python run_validation.py       # sensitivity grids, DSR, correlation, sleeve frontier
python report.py               # writes output/REPORT.pdf (+ charts, markdown copy)
```

Data: frozen daily OHLCV, a quarterly EPS panel, crypto perp prices (funding-
adjusted), daily perp funding rates and the ^IRX T-bill series under
`data/snapshot/` (no network access at any point). `data/loaders.py` only
reads that snapshot. Rebuild locally (not part of the submission):
`python scripts/fetch_data.py && python scripts/fetch_funding.py`.

## Layout

- `config.py` — all a-priori parameters (signals, sleeve risk budgets, risk overlays, costs, windows).
- `data/loaders.py` — offline snapshot loader (prices, fundamentals, funding, T-bill) and data fingerprint.
- `data/snapshot/` — frozen parquet panel used by every run.
- `signals/equity_core.py` — SPY-trend-gated long US equity basket (equity drift).
- `signals/btc_trend.py` — BTC EMA/RSI regime applied to the crypto complex (return engine).
- `signals/defensive.py` — trend-gated gold / duration / dollar (hit-rate engine: the only
  sleeve that is positive when equities fall).
- `signals/wd_mom.py` — crypto same-weekday cross-sectional momentum: equal-weight the
  coins with the strongest same-weekday return k weeks ago (Long 2020), over a 30-coin
  Binance USDT universe (delisted names included, so the panel is not survivorship-
  filtered) restricted each day to the top-12 by trailing 20-day dollar volume. Formed
  once a week at Friday close, low turnover.
- `signals/carry.py` — delta-neutral funding-carry pairs (spot vs short perp) and
  perp routing of directional crypto exposure. The carry overlay was built, tested
  and rejected (displaces blended gross of equal yield inside the cap); the perp
  routing stays on — a short perp leg collects funding where a short spot leg
  collects nothing.
- `signals/wq_earnings.py` — WQ-inspired cross-sectional earnings tilt, with publication lag.
  Built, tested, rejected (negative under next-open fills); off by default.
- `signals/` — also retains earlier research sleeves (trend/reversion/xs), unused by default.
- `portfolio/allocator.py` — sleeve risk budgets, vol targeting, drawdown throttle,
  crash guard, gross cap (with optional margin-netted accounting for matched
  spot/perp pairs).
- `costs.py` — commission + vol-scaled slippage per asset class.
- `backtest.py` — engine: signal at close t, fill at open t+1, single-pass cost
  accounting, causal T-bill cash yield on idle cash.
- `validation.py` + `run_validation.py` — deflated Sharpe, sensitivity, correlation, frontier.
- `tests/test_no_lookahead.py` — automated leakage checks (signals, engine overlays,
  carry gate, perp routing, earnings publication lag).
- `output/` — REPORT.pdf (the deliverable), charts, daily results, monthly series,
  diagnostics, frontiers.
- `output/research/` — ad-hoc grid searches backing the report's frontier discussion
  (not regenerated by `make all`).
